# База знаний: продуктовые гипотезы и выводы

Здесь живут гипотезы о продукте и трафике, их статус и результаты. Читают люди, агенты в репозитории и недельный ИИ-аналитик (`deploy/insights-agent/`): он сверяет метрики с гипотезами в статусе `running` и предлагает новые.

## Структура

```
knowledge/
  README.md              — этот файл, правила ведения
  learnings.md           — подтверждённые выводы: что точно знаем о пользователях и трафике
  hypotheses/
    _template.md         — шаблон гипотезы
    H-001-slug.md        — одна гипотеза = один файл
```

## Гипотеза

- Файл `hypotheses/H-NNN-короткий-slug.md`, номер — следующий свободный, номера не переиспользуются.
- Копируется из `_template.md`. Обязательные поля frontmatter: `id`, `title`, `status`, `area`, `created`, `updated`, `metric`.
- `status`:
  - `idea` — записали, не делали;
  - `planned` — решили делать;
  - `running` — выкатили, ждём данных (обязательно поле `started` и чем меряем);
  - `validated` / `rejected` — есть результат с цифрами;
  - `paused` — отложили, с причиной.
- `area`: `product`, `onboarding`, `monetization`, `traffic`, `seo`, `retention`.
- Формулировка: «Если сделать X для сегмента Y, то метрика Z изменится с A до B, потому что …». Без метрики и порога гипотеза не проверяема — так не пишем.
- Даты — абсолютные (`2026-11-15`), не «на прошлой неделе».
- Результат пишется в раздел «Результат» с цифрами и периодом, после чего меняется `status` и `updated`. Файл не удаляем: отклонённые гипотезы тоже знание.
- Подтверждённый или отклонённый вывод, который пригодится дальше, коротко переносим в `learnings.md` со ссылкой на гипотезу.

## Что сюда не кладём

- Персональные данные клиентов (email, телефоны, имена, названия проектов мастеров). Только агрегаты.
- Токены, пароли, содержимое `.env`.
- Описание того, как устроен код, — оно в `AGENTS.md` и в самом коде.

## Недельный ИИ-отчёт

Агент читает эту папку только на чтение (git pull), сам в репозиторий не пишет. Если его инсайт приняли — гипотезу заводит человек или агент в сессии разработки по правилам выше.
